# 妖怪ウォッチバスターズ 赤猫団 v2.3（月兎組モード）PoC

ゲーム内関数の呼び出しを実証するため、妖怪生成関数とアイテム追加関数を呼び出し、後処理を行う。

[脆弱性の解説](../../README.md)

## 動作確認環境

Old 3DS、妖怪ウォッチバスターズ 赤猫団（日本語版）v2.3の月兎組モードを対象とする。

## 実行手順

### 1. QR画像の用意

同梱の[ywb_qr_poc.png](ywb_qr_poc.png)を使用する。

再生成する場合は、Pythonとqrcode、Pillowを使い、[ywb_qr_poc.py](ywb_qr_poc.py)を実行する。

リポジトリのルートから実行する。

```sh
python -m pip install qrcode Pillow
python PoC/ywb/ywb_qr_poc.py
```

`PoC/ywb/`にQR画像の`ywb_qr_poc.png`が生成される。

### 2. ゲーム内の準備

次の状態をそろえる。

* 操作キャラはコンブさん。
* パーティーメンバーはコンブさん1体のみ。
* 1Fにうんがい鏡とウィスパーが出現済み。
* 建物のリフォーム（内装）はオーバーテクノ。
* 妖怪パッドのかべがみ(背景)はふんわりバスターズ。
* セーブデータのロード時のペナルティ警告が発生していない。

1FのQR読み取り担当NPC（コンブさん）に話しかけられる位置でセーブする。

### 3. 読み取りと確認

1. HOMEメニューに戻り、ソフトを終了する。
2. ソフトを起動し直し、月兎組を選択して、準備したセーブデータで再開する。
3. QR読み取り担当NPC（コンブさん）に話しかけ、用意したQR画像を読み取る。
4. 読み取り結果は「無効なQRコードを使用しています。」であることを確認し、QR読み取り画面を閉じる。


成功するとジバニャンが所有する妖怪に追加、持ち物にチョコボーが1個追加される。

## 制約と注意事項

確認した環境と手順では、想定したヒープ配置を繰り返し再現できている。ただし、想定した配置になるとは限らない。
このPoCはその配置を前提に固定アドレスを使用するため、実行時は記載した条件に合わせる必要がある。
実行により一部のメモリ領域が破損するため、実行後の正常な動作は保証しない。
