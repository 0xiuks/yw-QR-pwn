# 妖怪ウォッチ2 真打 v1.2 PoC

ゲーム内関数の呼び出しを実証するため、妖怪生成関数を呼び出し、後処理を行う。

[脆弱性の解説](../../README.md)

## 動作確認環境

Old 3DSでの妖怪ウォッチ2 真打（日本語版）v1.2

## 実行手順

### 1. QR画像の用意

同梱の[yw2_qr_poc.png](yw2_qr_poc.png)を使用する。

再生成する場合は、Pythonとqrcode、Pillowを使い、[yw2_qr_poc.py](yw2_qr_poc.py)を実行する。

リポジトリのルートから実行する。

```sh
python -m pip install qrcode Pillow
python PoC/yw2/yw2_qr_poc.py
```

`PoC/yw2/`にQR画像の`yw2_qr_poc.png`が生成される。

### 2. ゲーム内の準備

あらかじめ、次の状態をそろえておく。

* 主人公は男性（ケータモデル）。
* おとも妖怪はうんがい鏡。
* こぶた銀行内のうんがい鏡は解放済み。
* こぶた銀行内のキュッピーは解放済み。
* 妖怪パッドのかべがみ（背景）はひんやりブルー。
* セーブデータのロード時に赤鬼の警告が出ていない。  
天野家で夜まで寝て、ゲーム内時間を夜（18:00以上、翌6:00未満）に設定する。  
こぶた銀行のQR読み取り窓口のNPCに話しかけられる位置で、夜の時間帯にセーブする。

### 3. 読み取りと確認

1. HOMEメニューに戻り、ソフトを終了する。
2. ソフトを起動し直し、準備したセーブデータで再開する。
3. セーブデータをロードしたら、ほかの行動をせず、すぐに窓口のNPCに話しかけて、用意したQR画像を読み取る。
4. 読み取り結果が「このQRコードは　正しくないみたい。」であることを確認する。

成功するとジバニャンが所有する妖怪に追加。手持ちに空きがある場合は手持ちに、ない場合はひかえの妖怪に追加される。

## 制約と注意事項

確認した環境と手順では、想定したヒープ配置を繰り返し再現できている。ただし、想定した配置になるとは限らない。
このPoCはその配置を前提に固定アドレスを使用するため、実行時は記載した条件に合わせる必要がある。
実行により一部のメモリ領域が破損するため、実行後の正常な動作は保証しない。
